\hypertarget{md__r_e_a_d_m_e_autotoc_md25}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md__r_e_a_d_m_e_autotoc_md25}
Life-\/\+Saver Deluxe is a distributed home monitoring system consisting of a central Home Hub and multiple wireless sensor nodes.

The system monitors:\+


\begin{DoxyItemize}
\item Door and window status using magnetic sensors
\item Temperature
\item Humidity
\item Air pressure
\item Camera-\/based monitoring (experimental)
\end{DoxyItemize}

The architecture is designed around ESP32 devices communicating over Wi-\/\+Fi.
