\hypertarget{md_docs_2_h_w__documentation_autotoc_md1}{}\doxysection{\texorpdfstring{Purpose}{Purpose}}\label{md_docs_2_h_w__documentation_autotoc_md1}
The purpose of the system is to provide a modular home monitoring solution consisting of distributed magnetic sensors, environmental monitoring and camera surveillance.

The system includes:\+


\begin{DoxyItemize}
\item Magnetic sensors for doors and windows connected to ESP32-\/\+C3 sensor nodes
\item Temperature, pressure and humidity measurements using a BME280 sensor
\item Wireless communication between the Home Hub and sensor nodes
\item Camera-\/based monitoring using an ESP32-\/\+CAM module
\end{DoxyItemize}\hypertarget{md_docs_2_h_w__documentation_autotoc_md2}{}\doxysection{\texorpdfstring{Architecture}{Architecture}}\label{md_docs_2_h_w__documentation_autotoc_md2}
