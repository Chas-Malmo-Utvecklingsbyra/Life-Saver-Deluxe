Initializes the LCD backlight controller. 

Configures the I2C backlight device, sets the required IO expander registers, releases display and touch reset lines, and applies a default brightness level.

\begin{DoxyNote}{Note}
Must be called after I2C has been initialized.

Sets the display brightness. 

Converts a percentage value into the PWM value required by the backlight controller and transmits it over I2C.

Values outside the supported range are clamped to the configured minimum and maximum limits.
