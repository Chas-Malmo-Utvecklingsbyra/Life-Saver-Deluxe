Show how to handle a complete firmware update process with observers. Normally it\textquotesingle{}s hard to implement a firmware update process because in some cases
\begin{DoxyItemize}
\item the App needs to was for the UI (wait for a button press)
\item the UI needs to wait for the App (connecting or downloading) With observers these complex mechanisms can be implemented a simple and clean way. 
\end{DoxyItemize}
