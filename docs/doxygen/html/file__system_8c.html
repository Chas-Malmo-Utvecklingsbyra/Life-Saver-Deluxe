◆ File_System_Initialize()

File_System_Error File_System_Initialize ( File_System_Type type)

Initializes the whole Filesystem for saving files.

Parameters
file_systemInitializes File_System struct with values.
typeThe type of File_System which could be SPIFFS or FAT (which is not implemented).
Returns
Returns a File_System_Success on success but will return any other enumerator that fits the error best.
Note
FAT is not yet implemented.
Warning
Spiffs does not support sub-directories and when the chip experiences a power loss during a file system operation it could result in SPIFFS corruption, which may be able to be recovered.
