205/* Scan the string starting at ptr until the end of the next complete
206 token, but do not scan past eptr. Return an integer giving the
207 type of token.
208
209 Return XML_TOK_NONE when ptr == eptr; nextTokPtr will not be set.
210
211 Return XML_TOK_PARTIAL when the string does not contain a complete
212 token; nextTokPtr will not be set.
213
214 Return XML_TOK_INVALID when the string does not start a valid
215 token; nextTokPtr will be set to point to the character which made
216 the token invalid.
217
218 Otherwise the string starts with a valid token; nextTokPtr will be
219 set to point to the character following the end of that token.
220
221 Each data character counts as a single token, but adjacent data
222 characters may be returned together. Similarly for characters in
223 the prolog outside literals, comments and processing instructions.
224*/
225
