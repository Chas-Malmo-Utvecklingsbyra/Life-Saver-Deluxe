◆ lvgl_port_deinit()

esp_err_t lvgl_port_deinit ( void )

Deinitialize LVGL portation.

Note
This function deinitializes LVGL and stops the task if running. Some deinitialization will be done after the task will be stopped.
Returns
  • ESP_OK on success
  • ESP_ERR_TIMEOUT when stopping the LVGL task times out

◆ lvgl_port_init()

esp_err_t lvgl_port_init ( const lvgl_port_cfg_t * cfg)

Initialize LVGL portation.

Note
This function initialize LVGL and create timer and task for LVGL right working.
Returns
  • ESP_OK on success
  • ESP_ERR_INVALID_ARG if some of the create_args are not valid
  • ESP_ERR_INVALID_STATE if esp_timer library is not initialized yet
  • ESP_ERR_NO_MEM if memory allocation fails
