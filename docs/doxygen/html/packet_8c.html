◆ Packet_Build()

char * Packet_Build ( Packet_Job job,
const char * message )

Builds a Packet for commmunicating with our ESP32S3 via TCP.

This Packet_Build uses the Arena allocator, which means that it needs to be cleared via Arena_Reset() after usage to not harm other areas of the code.

Parameters
jobWhat type of Job to send.
messageThe data which should be put into the packet and sent.
Returns
Returns a char* to the Packet in the arena allocator memory.
Warning
Arena_Reset() should be used to clear the memory after having used the packet. DO NOT USE FREE!
